# MovieTrack 🎬

Projeto fullstack para gerenciar interações com filmes.  
Back-end em .NET 8 + PostgreSQL.  
Front-end em Next.js.

## Estrutura
- `back/`: API .NET
- `front/`: Frontend Next.js
- `docker-compose.yml`: Orquestra banco de dados

## Instruções
1. `docker compose up -d` para subir o PostgreSQL
2. Execute a API com `dotnet run`
3. Inicie o frontend com `npm run dev`
